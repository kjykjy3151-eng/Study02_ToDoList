# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱. 하루 10~20개 규모의 할 일을 관리한다.

## 현재 상태

**구현 완료** — 1차 범위의 기능이 모두 구현되어 동작한다. `index.html`을 열어 바로 쓸 수 있다.

| 단계 | 상태 |
|---|---|
| PRD 작성 | 완료 |
| 구현 계획 | 완료 |
| 구현 | 완료 |

## 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무, 개인, 공부)
- 전체 및 카테고리별 진행률
- 마감일 지정 (선택)
- 새로고침 후에도 데이터 유지

## 기술 스택

순수 JavaScript, HTML, CSS. 프레임워크와 빌드 도구를 쓰지 않는다.

```
index.html    마크업
style.css     스타일
app.js        전체 로직
tests.html    테스트 하네스 (개발용, 앱은 불러오지 않는다)
```

`tests.html`을 브라우저에서 열면 `app.js`의 함수와 화면 동작을 검사하고 통과, 실패 건수를 보여 준다. 앱 자체는 이 파일을 쓰지 않는다.

데이터는 브라우저의 localStorage에 저장한다. 서버와 계정이 없고, 모든 데이터는 사용 중인 브라우저 안에만 머무른다.

`index.html`을 더블클릭하면 `file://`로 열려 바로 동작한다. 로컬 서버나 설치 과정이 필요하지 않다. 이 제약 때문에 ES 모듈 대신 일반 스크립트를 쓴다 — 자세한 이유는 PRD 6절에 있다.

## 범위 밖

계정과 기기 간 동기화, 하위 할 일, 반복 일정, 알림, 태그, 검색, 드래그 재정렬, 다크 모드, 데이터 내보내기는 1차 구현에 포함하지 않는다.

> **알려진 리스크:** localStorage는 브라우저에서 "사이트 데이터 삭제"를 실행하면 함께 지워진다. 현재 백업 수단이 없다. JSON 내보내기와 가져오기는 후속 작업으로 남겨두었다.
