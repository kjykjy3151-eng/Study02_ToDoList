# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱. 하루 10~20개 규모의 할 일을 관리한다.

## 현재 상태

**구현 완료** — 1차 범위의 기능이 모두 구현되어 동작한다. `index.html`을 열어 바로 쓸 수 있다.

실행 주소: <https://kjykjy3151-eng.github.io/Study02_ToDoList/>

배포된 주소와 로컬에서 `file://`로 연 `index.html`은 **서로 다른 할 일 목록을 가진다.** localStorage가 출처(origin)별로 나뉘어 있기 때문이다. 한쪽에서 입력한 내용이 다른 쪽에 보이지 않아도 데이터가 사라진 것이 아니다.

## 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무, 개인, 공부)
- 전체 및 카테고리별 진행률 (카테고리 탭에 백분율도 표시)
- 모든 할 일을 완료하면 축하 표시
- 최근 7일 성과 표 (하루에 몇 건을 완료했는지)
- 마감일 지정 (선택)
- 새로고침 후에도 데이터 유지
- 넓은 화면에서는 2단(왼쪽 입력과 요약, 오른쪽 목록), 좁은 화면에서는 1단으로 접힘

## 기술 스택

순수 JavaScript, HTML, CSS. 프레임워크와 빌드 도구를 쓰지 않는다.

```
index.html    마크업
style.css     스타일
app.js        전체 로직
tests.html    테스트 하네스 (개발용, 앱은 불러오지 않는다)
```

`tests.html`을 브라우저에서 열면 `app.js`의 함수와 화면 동작을 검사하고 통과, 실패 건수를 보여 준다. 앱 자체는 이 파일을 쓰지 않는다.

데이터는 브라우저의 localStorage에 저장한다. 할 일은 `todos.v1`, 날짜별 완료 건수는 `dailyLog.v1` 키를 쓴다. 완료 기록을 따로 보관하므로 완료한 할 일을 삭제해도 그날의 기록은 지워지지 않는다. 서버와 계정이 없고, 모든 데이터는 사용 중인 브라우저 안에만 머무른다.

`index.html`을 더블클릭하면 `file://`로 열려 바로 동작한다. 로컬 서버나 설치 과정이 필요하지 않다. 이 제약 때문에 ES 모듈 대신 일반 스크립트를 쓴다 — 자세한 이유는 PRD 6절에 있다.

## 범위 밖

계정과 기기 간 동기화, 하위 할 일, 반복 일정, 알림, 태그, 검색, 드래그 재정렬, 다크 모드, 데이터 내보내기는 1차 구현에 포함하지 않는다.

> **알려진 리스크:** localStorage는 브라우저에서 "사이트 데이터 삭제"를 실행하면 함께 지워진다. 할 일(`todos.v1`)과 성과 기록(`dailyLog.v1`) 모두 해당된다. 현재 백업 수단이 없다. JSON 내보내기와 가져오기는 후속 작업으로 남겨두었다.
